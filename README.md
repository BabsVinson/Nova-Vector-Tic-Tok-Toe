# Alien Tic Tac Toe

Open `dist/index.html` in any modern browser to play. No installation is required. All artwork and game code are included and work offline.

You are orange Vector (X); the computer is blue Nova (O). Click an empty square and connect three in a row. Easy chooses random moves. Smart takes a win, blocks an immediate loss, then prefers the center and corners. Play again restarts the board. Scores stay in this browser when storage is available; Reset scores clears them. Changing difficulty starts a fresh round.

Project files: `dist/index.html` (page), `dist/style.css` (design), `dist/game.js` (rules, artwork, and interactions).
